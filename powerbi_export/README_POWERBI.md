# Power BI Integration & Reporting Guide

This directory contains business-ready, PII-compliant **Gold Layer Parquet export files** generated by the Medallion Data Lake pipeline.

---

## 📁 Exported Data Files

1. `customer_summary.parquet`: Customer demographics, credit score, risk segment, total accounts, total balance, total spent (PII fields `masked_name` and `masked_email` are deterministically tokenized via HMAC-SHA256).
2. `transaction_summary.parquet`: Aggregated transaction volume ($), transaction counts, and average transaction amount grouped by Region (State), Transaction Type, and Merchant Category.
3. `risk_segment_summary.parquet`: Customer counts, average credit score, and aggregate balance grouped by Bank Risk Segment (Low Risk, Medium Risk, High Risk, PEP).

---

## 🔌 Connecting Power BI Desktop

### Option 1: Direct Parquet Connection (Recommended for Local Files)
1. Open **Power BI Desktop**.
2. Click **Get Data** → **More...** → Search for **Parquet**.
3. Select **Parquet** and click **Connect**.
4. Browse to the path: `<repo-root>/powerbi_export/transaction_summary.parquet` (and repeat for `customer_summary.parquet` and `risk_segment_summary.parquet`).
5. Click **Load**.

### Option 2: PostgreSQL Database Connection (Live Audit & Governance Data)
1. Click **Get Data** → **PostgreSQL database**.
2. Enter Server: `localhost:5432`, Database: `postgres`.
3. Select Data Connectivity mode: **Import** or **DirectQuery**.
4. Enter credentials: User `postgres`, Password `postgres`.
5. Select tables: `audit_logs`, `roles`, `users`.

## 📊 Recommended Power BI Visualizations to Build

### Chart 1: Regional Transaction Volume (Clustered Bar Chart)
* **X-Axis:** `region` (State)
* **Y-Axis:** `total_volume` ($)
* **Legend:** `transaction_type` (Deposit, Withdrawal, Transfer, Payment)
* **Insight:** Displays geographic transaction concentration and liquidity movement across branches.

### Chart 2: Total Balance by Customer Risk Segment (Donut Chart)
* **Legend:** `risk_segment` (Low Risk, Medium Risk, High Risk, PEP)
* **Values:** `total_segment_balance`
* **Insight:** Provides executive compliance view of capital exposure across high-risk vs low-risk client segments.

### Chart 3: Credit Score vs Total Customer Balance (Scatter Plot)
* **X-Axis:** `credit_score`
* **Y-Axis:** `total_balance`
* **Details:** `customer_id`
* **Tooltips:** `masked_name`, `state`, `risk_segment`
* **Insight:** Allows analysts to identify high-net-worth customers without exposing raw PII.
